# Quick Voice Commands Reference

## 🚀 Getting Started

1. Click the microphone button in the navbar
2. Wait for the connection indicator
3. Start speaking!

## 📍 Navigation Commands

```
"Go to products"
"Take me to search"
"Navigate to cart"
"Show me the dashboard"
"Go to sign in"
"Take me home"
```

## 🤖 Page Interaction Commands

### Products Page
```
"Click the add to cart button"
"Add the wireless headphones to cart"
"Show me electronics products"
"Click the first product"
```

### Search Page
```
"Type 'laptop' in the search box"
"Select electronics category"
"Set minimum price to 50"
"Set maximum price to 200"
"Check the in stock only checkbox"
"Click the search button"
"Clear filters"
```

### Cart Page
```
"Remove the first item"
"Update quantity to 3"
"Clear the cart"
"Proceed to checkout"
```

### Forms
```
"Type my email as john@example.com"
"Fill in password"
"Click sign in"
"Click the submit button"
```

## 🎯 Complex Commands

```
"Go to search and find laptops under $1000"
"Navigate to products and add wireless headphones to cart"
"Search for electronics and show me only in-stock items"
"Go to cart and remove the first item"
"Type 'gaming mouse' in search and click search"
```

## 💡 Tips

- **Be specific**: "Click the first add to cart button" works better than "add to cart"
- **Use natural language**: The AI understands context and intent
- **Combine actions**: You can chain multiple commands together
- **Watch the console**: See what the AI is doing in real-time
- **Tool inputs in English**: All search queries, form inputs, and tool parameters must be in English (e.g., "laptop", "wireless mouse", "electronics")

## 🐛 Troubleshooting

**Command not working?**
- Try rephrasing: "add to cart" → "click the add button"
- Be more specific: "first button" → "first add to cart button"
- Check element is visible: Scroll to it first

**Element not found?**
- Use different words: "search box" → "search input"
- Try simpler commands: Break complex commands into steps
- Check console logs: See what elements were found
